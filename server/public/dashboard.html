Graceful Failure Handling Architecture

          

            When a department API experiences failure:
            
    
              
  • Circuit Breaker: Trips to OPEN state after 3 consecutive failures to prevent cascading downstream delays.
    • 
              
  • Asynchronous Queue: Requests are queued for automated exponential backoff retries.
    • 
              
  • Partial Success Result: Return available data for operational departments (e.g. Land 🟢, Electricity 🟢) with status PARTIAL_SUCCESS instead of crashing the transaction.
