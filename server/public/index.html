Enterprise Plant Establishment Interoperability Gateway

Connecting heterogeneous departmental systems—Land / Revenue, Electricity Discom, and Pollution Control Board—through a central adapter layer. We convert contrasting schemas into a Canonical Data Model without copying department databases.

🏭 Launch Plant Verification Workflow ⚙️ AI Schema Drift & Mapping Registry

📜 Land / Revenue API

Endpoint: GET /land/{survey_number}

Retrieves survey number, owner name, area in hectares, district, land classification, and mutation approval status.

Schema: owner_name, survey_no, area_hectare

⚡ Electricity Discom API

Endpoint: GET /electricity/{consumer_id}

Retrieves consumer ID, registered company name, sanctioned load (kW), connected load, meter status, and connection state.

Schema: registered_name, consumer_id, sanctioned_load

🌱 Pollution Control API

Endpoint: GET /pollution/{application_id}

Retrieves application number, industry name, industry category (Red/Orange/Green), CTE consent status, and validity period.

Schema: industry_name, application_no, consent_status

Architecture & Interoperability Highlights

🔄 Canonical Data Engine: Maps owner_name, registered_name, and industry_name into a unified organization_name.
🔐 Security & Consent Layer: Enforces JWT bearer authentication and verifies explicit user consent before dispatching API calls.
🛡️ Resilience & Circuit Breakers: Handles department timeouts gracefully without system crashes.
🤖 AI Schema Drift Handling: Detects field modifications (e.g. approved_load) and suggests mappings with confidence scores.
